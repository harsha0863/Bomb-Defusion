💣 Bomb Defusal Game
This is a fun and interactive web game where users must defuse a bomb by entering the correct code before the timer runs out. If they succeed, they see a green lightning background. If they fail, the bomb explodes with a blast animation and sound.

🚀 Features
⏱ 10-second countdown timer

🔐 Defusal input field

✅ Victory screen with green lightning background and hero message

💥 Explosion animation and sound if the player fails

🎇 Animated UI with glowing effects, pulsing bomb, and smooth fade-ins

🧾 How to Play
Open the game in a browser.
You'll see a countdown from 10.

Type the correct code (defuse) into the input box and press Enter.

If you're on time:

🎉 You see a “Bomb Defused” success screen.

If you're too late:

💣 The bomb explodes with sound and animation.

🔥 The screen shows an explosion and a red warning message.
